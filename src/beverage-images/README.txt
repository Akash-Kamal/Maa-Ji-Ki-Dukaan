Beverage Image Organization
===========================

The ZIP has been cleaned of macOS __MACOSX metadata files and the 71 actual image files
have been renamed and organized by category/brand.

Naming format:
    brand_product_pack-size.ext

Where the pack size was not visible in the source image, the filename intentionally omits
the size rather than inventing one.

A rename_manifest.csv is included with the original and new filenames.
